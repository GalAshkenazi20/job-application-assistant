# Resume writing and ATS rules

## How ATS filters read a resume

- They extract plain text, find sections by their usual names (Summary, Education, Experience,
  Projects, Skills) and match keywords from the job. Tables, columns, text boxes, icons, headers/footers
  and images often scramble or hide text – `resume.css` keeps everything in one plain column.
- Exact spelling matters: use the job's form of a term (Node.js / React / CI/CD). Write an acronym and
  its long form once when both are common ("Object-Oriented Programming (OOP)").
- A keyword counts more when it appears in context (a project bullet) than in a skills list only.
- PDF with real text is the safest format; the file name should carry the candidate's name.

## Bullet formula

**Action verb + what was built/done + how (technologies) + result (number, scale, outcome).**

- Weak: "Responsible for the backend of a study app."
- Strong: "Developed 12 REST endpoints in Node.js/Express with MongoDB for study groups and messaging."

Verbs: Built, Developed, Implemented, Designed, Optimized, Automated, Integrated, Tested, Analyzed,
Led, Taught, Mentored. Past tense for finished work, present for current roles. No "I", no
"responsible for", no "helped with" (say what part was done).

Numbers that are true and checkable: dataset sizes, accuracy, latency, number of endpoints/tests,
users, students taught, runs/scenarios, grade. Never estimate a number the candidate did not give.

## Students and juniors

- Projects are the experience: 3–4 strong projects with GitHub links beat a long list.
- Put the degree near the top with status ("one course remaining", "expected 2027").
- Non-tech jobs still count when framed honestly toward the role: teaching → communication,
  mentoring, explaining code; customer service → ownership; military service → responsibility.
- Coursework only if relevant and the projects are thin (4–6 courses, one line).

## Israeli market notes

- Hi-tech resumes are usually in English, one page for students/juniors, no photo.
- Leave out ID number, marital status, age/date of birth and address beyond the city.
- Military service is commonly listed in one line (role, unit, years).
- Student positions often require a minimum time left in the degree and 20–24 weekly hours –
  check these before applying.

## Cover letters

Short (200–350 words), specific to the company, built on 2 proofs from the resume. Many Israeli
companies do not read them, but they help with smaller companies, global companies, career changers
and emailed applications – write one per application and let the channel decide whether it is sent.
