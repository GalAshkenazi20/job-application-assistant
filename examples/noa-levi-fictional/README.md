# Example – fictional candidate

Everything here is invented to show what the skill produces: **Noa Levi** and **Acme Robotics** do not exist.

| File | What it shows |
|---|---|
| `master_resume.md` | a master resume built from three inbox files (an old CV, a project README, a course certificate) – note the `source:` and `VERIFY:` comments |
| `preferences.md` | saved job preferences |
| `job_Acme-Robotics_Backend-Student.md` | a saved job description |
| `shortlist_example.md` | the ranked batch table from a search round (a senior role ranks low despite matching keywords) |
| `Noa_Levi_Acme-Robotics_Backend-Student.pdf` | the tailored one-page resume |
| `cover_letter.pdf` | the tailored cover letter – no claim about time left in the degree, because the facts don't support it |
| `match_analysis.md` | scores, requirements vs. evidence, honest gaps, risks, recommendation |
| `ats_report_tailored.md` | the raw ATS report comparing master and tailored resume |
